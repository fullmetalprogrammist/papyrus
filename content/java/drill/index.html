Списки

Создание списка

Задание:

  • Создайте список строк из предоставленных имен:
import java.util.ArrayList;
import java.util.List;

public class Main {
    public static void main(String[] args) {
        // Создать список из имен:
        // "Tom", "Huck", "Becky", "Joe", "Jim", "Mary", "Polly"
    }
}
  • Используйте ArrayList.
  • Список надо инициализировать прямо при создании.

Решение:

import java.util.ArrayList;
import java.util.List;

public class Main {
    public static void main(String[] args) {
        var names = new ArrayList<String>(
            List.of("Tom", "Huck", "Becky", "Joe", "Jim", "Mary", "Polly")
        );
    }
}

Обход списка

Задание:

  • Дан список имен в виде строк.
  • Выведите имена в стандартный поток.
    • Сначала обойдите список в цикле.
    • Потом обойдите через stream api.
import java.util.ArrayList;
import java.util.List;

public class Main {
    public static void main(String[] args) {
        var names = new ArrayList<String>(
            List.of("Tom", "Huck", "Becky", "Joe", "Jim", "Mary", "Polly")
        );

        // Вывести список через цикл
        // Вывести список через stream api
    }
}

Решение:

import java.util.ArrayList;
import java.util.List;

public class Main {
    public static void main(String[] args) {
        var names = new ArrayList<String>(
            List.of("Tom", "Huck", "Becky", "Joe", "Jim", "Mary", "Polly")
        );

        for (var name: names) {
            System.out.println(name);
        }
        
        names.stream()
            .forEach(name -> System.out.println(name));
    }
}

Фильтрация списка, размер

Задание:

  • Выберите из списка имена, длина которых больше 3 символов.
    • Результат тоже должен быть в виде списка.
  • Выведите размер получившегося списка.
  • Выведите сам получившийся список.
import java.util.ArrayList;
import java.util.List;

public class Main {
    public static void main(String[] args) {
        var names = new ArrayList<String>(
            List.of("Tom", "Huck", "Becky", "Joe", "Jim", "Mary", "Polly")
        );
        
        // Выбрать длинные имена в отдельный список
        // Вывести размер этого списка
        // Вывести этот список
}

Решение:

import java.util.ArrayList;
import java.util.List;

public class Main {
    public static void main(String[] args) {
        var names = new ArrayList<String>(
            List.of("Tom", "Huck", "Becky", "Joe", "Jim", "Mary", "Polly")
        );

        var longNames = names.stream()
            .filter(name -> name.length() > 3)
            .toList();

        System.out.println(longNames.size());
        longNames.forEach(name -> System.out.println(name));
    }
}

```java
import java.util.ArrayList;
import java.util.List;

public class Main {
    public static void main(String[] args) {
        var names = new ArrayList<String>(
            List.of("Tom", "Huck", "Becky", "Joe", "Jim", "Mary", "Polly")
        );

            System.out.println(name);
        }
        
        names.stream()

    }
}
```

- У списка есть собственный метод `.forEach()`, так что в общем-то stream api в данном случае не обязательно использовать.

```java
import java.util.ArrayList;

        var names = new ArrayList<String>(
            List.of("Tom", "Huck", "Becky", "Joe", "Jim", "Mary", "Polly")

    }
```
